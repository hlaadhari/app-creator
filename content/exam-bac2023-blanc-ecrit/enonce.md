# Bac Blanc 2023 — Épreuve Écrite Systèmes & Technologies de l'Informatique

**Durée :** 3 heures — **Coefficient :** 1.8 — **Barème total :** 20 points

## Exercice N° 1 (3 pts)

Validation Vrai/Faux et QCM sur JavaScript (`String.fromCharCode`, `isNaN`), SQL (`SELECT`, `Jointure`, `ON UPDATE CASCADE`) et PHP (`checkdate`).

## Exercice N° 2 (5 pts)

Base de données `Gestion_Transfert` (`Service`, `Employe`, `Transfert`) : représentation textuelle, cardinalités, contrainte `CHECK (Duree > 0)`, `ON DELETE CASCADE`, création de la table `Fonction`.

## Exercice N° 3 (6 pts)

Formulaire d'authentification HTML (`GET`, `Connexion.php`, `onsubmit`), validation JS `Test()`, et traitement PHP `Connexion.php` sur la table `Identification`.

## Exercice N° 4 (6 pts)

Requêtes SQL sur `CONSTRUCTEUR`, `MODELE`, `VEHICULE`, `VENDEUR`, `ANNONCE` (`UPDATE`, `DELETE`, `MIN`, `SELECT DISTINCT`, `GROUP BY`).
