1. Structure de Base & Syntaxe PHP

Tout script PHP est délimité par les balises <?php et ?>. Chaque instruction se termine obligatoirement par un point-virgule ;. Les variables commencent impérativement par le symbole dollar $.

Syntaxe & Affichage PHP 
<?php
// Déclaration de variables typées dynamiquement
$titre = "Épreuve Pratique STI";
$annee = 2024;
$moyenne = 15.75;
$reussite = true;

// Affichage avec echo et concaténation via le point (.)
echo "Session : " . $titre . " (" . $annee . ")<br>";
echo "Moyenne obtenue : <strong>" . $moyenne . "/20</strong>";

// Structures conditionnelles classiques
if ($moyenne >= 10) {
  echo "<p style='color:green;'>Admis avec succès !</p>";
} else {
  echo "<p style='color:red;'>Ajourné.</p>";
}

// Boucle for usuelle
for ($i = 1; $i <= 5; $i++) {
  echo "Étape $i <br>";
}
?>

2. Récupération des Données de Formulaire

Lorsqu'un formulaire HTML transmet ses champs via method="post", les valeurs sont accessibles sur le serveur via le tableau associatif superglobal $_POST ou par l'instruction extract($_POST).

Récupération standard et sécurisée PHP 
<?php
// Méthode 1 : Récupération explicite champ par champ (Recommandée)
if (isset($_POST["cin"]) && isset($_POST["nom"])) {
  $cin = trim($_POST["cin"]);
  $nom = trim($_POST["nom"]);
  $genre = $_POST["genre"];
  $section = $_POST["section"];
}

// Méthode 2 : Importation globale via extract() (Fréquente au Bac)
extract($_POST);
// Crée directement les variables $cin, $nom, $genre, $section...
?>

3. Fonctions Natives Essentielles

Les fonctions indispensables pour valider et formater les entrées utilisateurs selon le programme officiel :

Fonction PHP Exemple d'Appel Résultat Usage type Bac STI
strlen($ch) strlen("12345678") 8 Tester la longueur d'une chaîne (CIN, code postal).
substr($ch, deb, lg) substr("2024-05-18", 0, 4) "2024" Extraire une sous-chaîne ou décomposer une date.
strpos($ch, sub) strpos("test@dom.tn", "@") 4 (ou false) Vérifier la position d'un caractère.

strtolower($ch) strtolower("ADMIN") "admin" Normaliser le texte en minuscules.

date($format) date("Y-m-d H:i:s") "2024-06-12 10:30:00" Générer la date et l'heure système actuelles.

4. Interfaçage MySQLi Procédural (Standard Officiel Bac STI)

Au Bac STI, toutes les interactions avec le serveur SGBD MySQL se réalisent via l'extension procédurale mysqli_*.

Fonction MySQLi Syntaxe & Paramètres Rôle
mysqli_connect() mysqli_connect($hote, $user, $mdp, $bdd) Établit la connexion avec le serveur MySQL. Retourne l'identifiant de connexion ou false.
mysqli_query() mysqli_query($cnx, $sql) Exécute la requête SQL. Retourne un jeu de résultats (pour SELECT) ou true/false (pour INSERT/UPDATE/DELETE).
mysqli_num_rows() mysqli_num_rows($res) Renvoie le nombre de lignes retournées par un SELECT (très utile pour tester l'unicité).
mysqli_fetch_array() mysqli_fetch_array($res) Lit une ligne du jeu de résultats sous forme de tableau associatif et indexé.
mysqli_affected_rows() mysqli_affected_rows($cnx) Renvoie le nombre de lignes modifiées ou supprimées par la dernière requête.
mysqli_error() mysqli_error($cnx) Retourne le libellé textuel de l'erreur SQL survenue.
mysqli_close() mysqli_close($cnx) Ferme proprement la connexion à la base de données.

5. Patron Canonique de Script d'Insertion & Consultation (Bac STI)

Voici la structure officielle d'un fichier enregistrement.php respectant l'ensemble des critères de notation :

Fichier enregistrement.php complet PHP 
<?php
// 1. Connexion au serveur de base de données
$cnx = mysqli_connect("localhost", "root", "", "gestion_bac") 
       or die("Erreur de connexion au serveur MySQL : " . mysqli_connect_error());

// 2. Récupération des données postées
$cin = trim($_POST["cin"]);
$nom = trim($_POST["nom"]);
$genre = $_POST["genre"];
$section = $_POST["section"];

// 3. Vérification d'unicité (Le candidat existe-t-il déjà ?)
$req_verif = "SELECT cin FROM candidat WHERE cin = '$cin'";
$res_verif = mysqli_query($cnx, $req_verif) 
             or die("Erreur lors de la vérification : " . mysqli_error($cnx));

if (mysqli_num_rows($res_verif) > 0) {
  // Enregistrement déjà existant : message d'erreur
  echo "<h3 style='color:red;'>Erreur : Le candidat portant le CIN $cin est déjà enregistré !</h3>";
} else {
  // 4. Insertion du nouvel enregistrement
  $req_insert = "INSERT INTO candidat (cin, nom, genre, section, date_inscription) 
                 VALUES ('$cin', '$nom', '$genre', '$section', NOW())";
                 
  $res_insert = mysqli_query($cnx, $req_insert) 
                or die("Erreur lors de l'insertion : " . mysqli_error($cnx));
                
  if (mysqli_affected_rows($cnx) > 0) {
    echo "<h3 style='color:green;'>Félicitations, candidat $nom enregistré avec succès !</h3>";
    echo "<p>Numéro CIN : <strong>$cin</strong> | Section : <strong>$section</strong></p>";
  }
}

// 5. Affichage récapitulatif du nombre d'inscrits par section
echo "<hr><h4>Statistiques des candidatures par section :</h4>";
$req_stats = "SELECT section, COUNT(*) AS total FROM candidat GROUP BY section";
$res_stats = mysqli_query($cnx, $req_stats);

echo "<table border='1' cellpadding='6' cellspacing='0'>
        <tr bgcolor='#f1f5f9'>
          <th>Section</th>
          <th>Nombre de Candidats</th>
        </tr>";
        
while ($ligne = mysqli_fetch_array($res_stats)) {
  echo "<tr>
          <td>" . $ligne["section"] . "</td>
          <td align='center'><b>" . $ligne["total"] . "</b></td>
        </tr>";
}
echo "</table>";

// 6. Fermeture de la connexion
mysqli_close($cnx);
?>
