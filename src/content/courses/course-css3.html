1. Sélecteurs, Combinaisons et Pseudo-Classes

Le sélecteur désigne les éléments HTML ciblés par la règle de style. La priorité suit l'ordre : Style en ligne > #identifiant > .classe > balise.

CSS3 Exemples des différents types de sélecteurs 
/* 1. Sélecteur universel : réinitialise les marges par défaut */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* 2. Sélecteur de balise : s'applique à tous les titres h1 */
h1 {
  color: #1e3a8a;
  font-family: Arial, sans-serif;
  margin-bottom: 12px;
}

/* 3. Sélecteur d'identifiant unique (#) */
#formCandidat {
  background-color: #f8fafc;
  padding: 20px;
}

/* 4. Sélecteur de classe réutilisable (.) */
.champ-obligatoire {
  border-left: 3px solid #dc2626;
}

/* 5. Sélecteur combiné : balise ET classe */
input.erreur {
  border-color: #ef4444;
  background-color: #fef2f2;
}

/* 6. Pseudo-classes d'état des hyperliens et boutons */
a:link {
  color: #2563eb;
  text-decoration: none;
}
a:visited {
  color: #7c3aed;
}
a:hover, button:hover {
  color: #1d4ed8;
  text-decoration: underline;
  cursor: pointer;
}
button:active {
  transform: scale(0.98);
}

2. Le Modèle de Boîte (Box Model)

Chaque élément HTML est représenté par une boîte rectangulaire composée de quatre zones concentriques : le contenu (width/height), les marges intérieures (padding), la bordure (border) et les marges extérieures (margin).

CSS3 Configuration complète du modèle de boîte 
/* Fiche candidat stylisée selon le modèle de boîte standard */
.carte-profil {
  /* Dimensions du bloc */
  width: 420px;
  max-width: 100%;
  
  /* Marges intérieures : espace entre texte et bordure */
  padding: 16px 24px;
  
  /* Bordure visible avec angles arrondis */
  border-width: 2px;
  border-style: solid;
  border-color: #cbd5e1;
  border-radius: 8px; /* Coins arrondis */
  
  /* Ombre portée élégante (décalage-X, décalage-Y, flou, couleur) */
  box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1);
  
  /* Marges extérieures : centrage horizontal automatique */
  margin: 30px auto;
  
  /* Type d'affichage */
  display: block;
}

/* Contrôle du type d'affichage des balises */
.badge-niveau {
  display: inline-block;
  padding: 4px 10px;
  border-radius: 9999px;
  background-color: #e0f2fe;
  color: #0369a1;
  font-weight: bold;
}

.element-masque {
  display: none; /* Disparaît complètement du flux d'affichage */
}

3. Positionnement Spatial et Débordement (overflow)

La propriété position détermine comment un élément est placé par rapport au flux normal du document.

Valeur de position Description & Comportement
static Position par défaut dans le flux normal (top/left sans effet).
relative Décalé par rapport à sa position normale sans impacter ses voisins. Sert de repère pour les enfants absolus.
absolute Retiré du flux normal, positionné par rapport au premier ancêtre non static.
fixed Fixé par rapport à la fenêtre du navigateur (ne défile pas au scroll).
sticky Se comporte comme relative jusqu'à un seuil de défilement, puis se fige comme fixed.
CSS3 Exemple de bandeau fixe et conteneur avec scrollbar 
/* Barre d'en-tête figée en haut de l'écran */
.header-fixe {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 60px;
  background-color: #0f172a;
  color: #ffffff;
  z-index: 1000; /* Toujours au premier plan */
  opacity: 0.95;
}

/* Pastille absolue positionnée dans le coin d'une carte relative */
.carte-parent {
  position: relative;
  width: 300px;
  height: 200px;
  border: 1px solid #ccc;
}

.pastille-promo {
  position: absolute;
  top: 10px;
  right: 10px;
  background-color: #e11d48;
  color: #fff;
  padding: 4px 8px;
}

/* Zone avec défilement interne automatique en cas de débordement */
.zone-commentaires {
  width: 100%;
  height: 180px;
  overflow: auto; /* Affiche une barre de défilement si nécessaire */
  border: 1px solid #e2e8f0;
}

4. Typographie, Alignement et Couleurs

Les règles typographiques définissent la lisibilité et l'aspect des textes.

CSS3 Styles de texte, alignement et ombrage 
body {
  /* Famille de polices avec alternatives de repli */
  font-family: "Segoe UI", Roboto, Arial, sans-serif;
  font-size: 16px;
  line-height: 1.5; /* Interligne confortable */
  color: #334155;   /* Couleur de texte sombre lisible */
}

.titre-section {
  font-size: 24px;
  font-weight: 700;           /* Gras */
  font-style: normal;
  text-align: center;         /* Centrage horizontal */
  text-transform: uppercase;  /* MAJUSCULES automatiques */
  letter-spacing: 1.5px;      /* Espacement inter-lettres */
  color: #1e293b;
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.15); /* Ombre de texte */
}

.texte-justifie {
  text-align: justify;
}

.prix-important {
  color: #059669;
  font-weight: bold;
}

5. Arrière-Plans et Effets Visuels

CSS3 offre un contrôle fin sur les couleurs unies, dégradés et images de fond.

CSS3 Images de fond et dimensionnement 
/* Section héro avec image d'arrière-plan centrée et non répétée */
.banniere-accueil {
  background-color: #1e1e2f;
  background-image: url("images/fond-lycee.jpg");
  background-repeat: no-repeat;
  background-position: center center;
  background-size: cover; /* Remplit tout le conteneur sans déformation */
  min-height: 280px;
  color: #ffffff;
}

/* Dégradé linéaire CSS3 */
.bouton-degrade {
  background-image: linear-gradient(135deg, #3b82f6 0%, #1d4ed8 100%);
  color: #ffffff;
  border: none;
  border-radius: 6px;
  padding: 10px 20px;
}

6. Transformations 2D et Transitions Fluides

Les transformations 2D permettent de modifier l'échelle (scale), la rotation (rotate) ou le déplacement (translate). Couplées aux transitions, elles animent agréablement les interactions.

CSS3 Animation au survol avec transition fluide 
/* Bouton interactif avec effet d'agrandissement et transition */
.btn-interactif {
  display: inline-block;
  background-color: #2563eb;
  color: #ffffff;
  padding: 12px 24px;
  border-radius: 6px;
  text-decoration: none;
  font-weight: 600;
  
  /* Définition de la transition : propriété, durée, fonction de lissage */
  transition-property: transform, background-color, box-shadow;
  transition-duration: 0.3s;
  transition-timing-function: ease-in-out;
  transition-delay: 0s;
}

/* Effet déclenché lors du survol de la souris */
.btn-interactif:hover {
  background-color: #1d4ed8;
  transform: scale(1.05) translateY(-2px); /* Légère mise à l'échelle et élévation */
  box-shadow: 0 10px 15px -3px rgba(37, 99, 235, 0.3);
}

/* Image pivotante au survol */
.vignette-robot {
  transition: transform 0.4s ease;
}
.vignette-robot:hover {
  transform: rotate(5deg) scale(1.08);
}
