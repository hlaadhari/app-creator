1. Types de Données SGBD (MySQL)

Le choix judicieux du type de données garantit l'intégrité et la performance de la base de données relationnelle :

Type SQL Description & Format Exemple d'Usage Bac STI
INT / INTEGER Entier relatif 32 bits (-2^31 à +2^31 - 1). Identifiant auto-incrémenté id INT AUTO_INCREMENT, nombre de places.
DECIMAL(M, D) Nombre décimal exact (M chiffres au total, D après la virgule). Moyenne DECIMAL(4,2) (ex: 15.75), Prix DECIMAL(6,3) (DT).
CHAR(N) Chaîne de caractères à longueur fixe de N caractères. Numéro de CIN CHAR(8), Code pays CHAR(2), Genre CHAR(1).
VARCHAR(N) Chaîne de caractères à longueur variable jusqu'à N caractères. Nom VARCHAR(30), Email VARCHAR(50), Adresse VARCHAR(100).
DATE Date calendaire au format officiel 'AAAA-MM-JJ'. Date de naissance date_naiss DATE, Date inscription.
TIME Heure au format 'HH:MM:SS'. Heure de début d'épreuve heure_deb TIME.
TEXT Chaîne longue pour du texte libre non indexé. Remarques ou observations du correcteur.

2. Contraintes d'Intégrité

Les règles assurant la cohérence sémantique des données au sein de la base :

Contrainte Signification & Rôle Exemple de Syntaxe
PRIMARY KEY Identifie de façon unique et non nulle chaque enregistrement. PRIMARY KEY (cin)
FOREIGN KEY ... REFERENCES Garantit l'intégrité référentielle en liant un champ à la clé primaire d'une autre table. FOREIGN KEY (code_sec) REFERENCES section(code)
NOT NULL Interdit la valeur nulle pour ce champ. nom VARCHAR(30) NOT NULL
UNIQUE Empêche les doublons dans une colonne. email VARCHAR(60) UNIQUE
CHECK Valide une condition logique sur la valeur insérée. CHECK (moyenne BETWEEN 0 AND 20)
DEFAULT Attribue une valeur par défaut en cas d'omission. statut VARCHAR(10) DEFAULT 'En attente'
ON DELETE / UPDATE CASCADE Propage automatiquement les suppressions ou mises à jour aux tables filles. ON DELETE CASCADE ON UPDATE CASCADE

3. Langage de Définition de Données (LDD)

Commandes pour créer, modifier ou supprimer la base et ses tables :

Création de Base & Tables SQL 
-- Création de la base de données
CREATE DATABASE IF NOT EXISTS gestion_lycee;
USE gestion_lycee;

-- Création de la table 'section' (Table mère)
CREATE TABLE IF NOT EXISTS section (
  code_sec VARCHAR(10),
  libelle_sec VARCHAR(50) NOT NULL,
  CONSTRAINT pk_section PRIMARY KEY (code_sec)
);

-- Création de la table 'eleve' (Table fille avec clé étrangère)
CREATE TABLE IF NOT EXISTS eleve (
  cin CHAR(8),
  nom VARCHAR(30) NOT NULL,
  prenom VARCHAR(30) NOT NULL,
  genre CHAR(1) CHECK (genre IN ('M', 'F')),
  date_naiss DATE NOT NULL,
  code_sec VARCHAR(10) NOT NULL,
  moyenne DECIMAL(4, 2) DEFAULT 0.00,
  CONSTRAINT pk_eleve PRIMARY KEY (cin),
  CONSTRAINT fk_eleve_section FOREIGN KEY (code_sec) 
    REFERENCES section(code_sec) 
    ON DELETE RESTRICT ON UPDATE CASCADE,
  CONSTRAINT chk_moyenne CHECK (moyenne BETWEEN 0 AND 20)
);

-- Modifications de structure (ALTER TABLE)
-- Ajouter une colonne
ALTER TABLE eleve ADD COLUMN telephone CHAR(8);

-- Modifier le type d'une colonne existante
ALTER TABLE eleve MODIFY COLUMN nom VARCHAR(40) NOT NULL;

-- Supprimer une colonne
ALTER TABLE eleve DROP COLUMN telephone;

-- Supprimer une table
DROP TABLE IF EXISTS eleve;

4. Langage de Manipulation de Données (LMD)

Commandes d'insertion, mise à jour et suppression des enregistrements :

Insertion, Mise à jour & Suppression SQL 
-- 1. Insertion d'enregistrements (INSERT INTO)
INSERT INTO section (code_sec, libelle_sec) 
VALUES ('SI', 'Sciences de l''Informatique'),
       ('MATH', 'Mathématiques'),
       ('SC', 'Sciences Expérimentales');

INSERT INTO eleve (cin, nom, prenom, genre, date_naiss, code_sec, moyenne) 
VALUES ('08945612', 'BEN SALAH', 'Mohamed', 'M', '2006-04-15', 'SI', 16.50),
       ('07123984', 'TRABELSI', 'Amina', 'F', '2006-11-20', 'SI', 17.25),
       ('09874561', 'GHARBI', 'Sami', 'M', '2005-08-05', 'MATH', 13.00);

-- 2. Mise à jour de données (UPDATE)
UPDATE eleve 
SET moyenne = moyenne + 0.50 
WHERE code_sec = 'SI' AND moyenne <= 19.50;

-- 3. Suppression ciblée (DELETE)
DELETE FROM eleve 
WHERE cin = '09874561';

5. Langage d'Interrogation de Données (LID / SELECT)

La clause SELECT permet d'extraire et filtrer les informations selon des critères précis.

Requêtes SELECT, Jointures & Fonctions d'Agrégation SQL 
-- 1. Sélection avec projection et critères de filtrage
SELECT cin, CONCAT(nom, ' ', prenom) AS nom_complet, moyenne
FROM eleve
WHERE code_sec = 'SI' AND moyenne >= 10.00
ORDER BY moyenne DESC;

-- 2. Jointure relationnelle entre deux tables
SELECT e.cin, e.nom, e.prenom, s.libelle_sec, e.moyenne
FROM eleve e
INNER JOIN section s ON e.code_sec = s.code_sec
WHERE YEAR(e.date_naiss) = 2006;

-- 3. Fonctions d'agrégation (COUNT, AVG, SUM, MAX, MIN)
SELECT COUNT(*) AS total_eleves,
       ROUND(AVG(moyenne), 2) AS moyenne_generale,
       MAX(moyenne) AS meilleure_note,
       MIN(moyenne) AS note_minimale
FROM eleve;

-- 4. Regroupement par critères (GROUP BY) et filtrage post-agrégation (HAVING)
SELECT s.libelle_sec, 
       COUNT(e.cin) AS effectif, 
       ROUND(AVG(e.moyenne), 2) AS moyenne_section
FROM section s
LEFT JOIN eleve e ON s.code_sec = e.code_sec
GROUP BY s.code_sec, s.libelle_sec
HAVING effectif >= 1
ORDER BY moyenne_section DESC;

-- 5. Fonctions SQL sur les dates
-- YEAR(d), MONTH(d), DAY(d), NOW()
SELECT cin, nom, date_naiss,
       (YEAR(NOW()) - YEAR(date_naiss)) AS age
FROM eleve
WHERE MONTH(date_naiss) = 4;
